# Faultvane

Faultvane makes resilience libraries for distributed services.

| Repository | Content |
|---|---|
| [faultvane-go](https://github.com/faultvane/faultvane-go) | Resilience library for Go. Its first component is a distributed circuit breaker with shared state in Redis and a local fallback. |

The project is in the design phase. The [roadmap](https://github.com/faultvane/faultvane-go/blob/main/docs/roadmap.md) gives the plan.
